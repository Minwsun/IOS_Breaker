# Public client options: evidence rather than support promises

Reviewed 2026-10-21. No binary was downloaded, installed, signed or executed. This supplements the source tracing in `premium-research-luna.md` and the script repair in `spotify-current.md`.

| Mechanism / public source | Concrete current evidence | Limit / assessment |
| --- | --- | --- |
| Proxy response rewrite: [app2smile/rules](https://github.com/app2smile/rules) | MIT source, stable February 25 and test March 4 handlers; local repo has pinned copies and a new wire-preserving processor. | Known client response layout only. No current device proof for Spotify 9.1.92. A changed UI is not a server subscription. |
| Modified client: [SideloadLabs/EeveeSpotifyReincarnated](https://github.com/SideloadLabs/EeveeSpotifyReincarnated) | Public GPL-3.0 project; [v7.0.0 release](https://github.com/SideloadLabs/EeveeSpotifyReincarnated/releases) dated October 5, 2026. README specifically targets Spotify 9.1.88, minimum iOS 16.1. | Most relevant maintained public client-patch candidate found. Requires a matching client build and a separate build/signing/install workflow. Current 9.1.92 support is unverified. Upstream excludes server-backed Very High audio, native playlist downloads and Jam hosting/remote joining. |
| Modified client: [zbzxbg/EeveeSpotifyEvolved](https://github.com/zbzxbg/EeveeSpotifyEvolved) | Public v1.0.0 targets 9.1.88; README says development update October 11, build 147, and describes a specific test device. | Primarily lyrics/UI enhancements; only some features are reported tested. README has version-dependent GPL/PolyForm licensing claims inconsistent with a simple repo badge. No code imported or blanket support claim. |
| Original Eevee lineage: [whoeevee/EeveeSpotifyReborn](https://github.com/whoeevee/EeveeSpotifyReborn) | Archived December 28, 2025; discontinuation documented. The original EeveeSpotify URL was unavailable during checking. | Historical source, not evidence of maintenance for today's Spotify. |
| Generic in-app purchase hooks: [Paisseon/SatellaJailed](https://github.com/Paisseon/SatellaJailed) | AGPL-3.0 source, declared iOS 12–16 scope. | Not Spotify-specific, no current 1Blocker/Endel/Spotify build compatibility evidence. Do not infer support from generic purchase-hook claims or newer-looking fork names. |
| VPN/DNS routing | Can change transport, region routing, DNS and reachability. 1Blocker documents [VPN conflicts](https://support.1blocker.com/en/articles/9313600-in-app-tracking-filter-vpns). | Routing alone does not create purchase records. Transport changes can help a playback failure but need the user's actual symptom to test. |

Specific release notes take precedence over a generic README claim such as “9.1.x”. Reincarnated's older `common_issues.md` still names 9.1.68, which conflicts with newer release/README targets; the discrepancy is recorded instead of presenting all docs as consistent. Evolved's source-license claims need separate review before any mirror. No IPA, credentials, receipt, signing certificate or third-party account is included in this repository.
